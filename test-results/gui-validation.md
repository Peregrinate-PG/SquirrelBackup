# 原生界面验证记录

AppKit 进程初始化、三页面离屏 PDF 导出、12 项内部业务动作断言通过。

初次在执行沙箱中启动 AppKit 的进程被系统在注册应用阶段中止；经自动审批允许工作区自建程序访问本机图形会话后测试正常执行，无需用户输入管理员密码。此现象属于开发工具沙箱限制，不能推断普通双击启动会失败。

离屏渲染检查修正了自定义背景绘制的裁剪与颜色状态隔离，并固定浅色外观，避免主题冲突。截图是应用自身导出的预览，不是桌面录屏。

内部动作测试覆盖空输入、密码框开关、忙碌状态、按钮禁用、加密备份发布、错误密码不发布结果及错误提示、恢复字节一致、列表显示、验证成功、停止后重新启用按钮和完成日志。

真实鼠标／键盘交互、文件选择器、屏幕截图和完整 GUI 端到端人工验收尚未完成。
