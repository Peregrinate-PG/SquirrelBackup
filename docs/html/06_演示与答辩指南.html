随包第9讲《知识拓展与项目完善》第38–40页明确：完善在线分组文档；PPT介绍3分钟、老师/助教在学生指导下操作7分钟、项目视频不超过2分钟。答辩在2026年11月18日上午上课时；报告、PPT、源码与可执行程序及构建脚本、视频，由组长于当日23:59前打包交成电慕课；AI辅助程序设计学习证书每位同学自行提交。第0讲的3分钟视频和邮箱提交为早先章节口径，当前按第9讲准备；后续若有更新课程通知再据此调整。

第2讲第38页将GitHub/Gitee在线版本库与git开发列为项目要求；Teambition或类似项目看板为鼓励项。现有本地历史不能替代在线仓库，需本人补齐实际在线记录，不伪造历史协作。

2 本机交互验收

  1. 执行make all及bash scripts/demo.sh，记录实际输出。使用新生成的演示数据，包含中文名、空目录、文本、大文件、链接、FIFO。
  2. 在Finder中打开当前SquirrelBackup.app，检查三页面的布局和切换。实际点文件选择器，分别验证选择、取消、中文路径和空格路径。
  3. 创建新的GUI备份.sqbk，启用压缩；恢复到尚不存在的GUI恢复目录，对比普通文件内容/哈希、目录结构及链接/FIFO类型。再次选择已有恢复目录，应失败且不改变已有内容。
  4. 创建加密备份，先用错误密码验证/恢复，应失败且不产生成功目标；再用正确密码验证/恢复。密码不出现在日志或截图。
  5. 定时任务设间隔3秒、保留2份；产生至少3次快照后核对数量，并确认仓库中预先放置的无关文件保留。点击停止，完成当前快照后退出；观察等待阶段和正在备份阶段的差异。
  6. 实时任务启动后修改源目录，等两个稳定观察周期和备份耗时，确认新增快照；持续修改不承诺立即备份。
  7. 在自动任务运行时关闭窗口或退出：0.1.1应记住请求，等待当前操作完成后自动关闭/退出。单次备份/恢复仍等待完成，不提供强制中断。退出后核对已发布快照可验证。
  8. 填写路径、筛选、间隔/份数与开关，正常退出并重启：白名单表单参数应恢复，三个密码输入框为空，不自动启动任务。截图与记录只标真实执行结果。

GUI自动任务不继承创建页的名字与排除规则，仍采用默认全量选项和任务页密码；完整筛选使用CLI。配置保存不等于后台运行或跨进程恢复任务。详细逐项记录表见08_提交前验收清单.md。

老师/助教负责操作，同学指引并回答问题。提前准备小而有代表性的数据，设置全新的目标路径，避免现场复用已有目录。

7 常见答辩问题

先压缩后加密：压缩利用冗余，加密后接近随机，通常难以再压缩。

已有目录为什么拒绝恢复：发布新目录可降低误覆盖和链接攻击风险；需要合并时先恢复到新目录再比较。

实时是否绝对即时：使用轮询与稳定检测，持续变化会延迟；未提供文件系统事务一致性或内核事件级保证。

加密是否自研：协议封装由项目编写，AES、HMAC、PBKDF2等原语来自系统库，按课程依赖规则如实申报。

设置保存会不会保存密码：0.1.1只持久化白名单表单字段，密码不保存；已保存加密开关仍要求重新输入密码。

点击停止是否立即中断文件写入：不会。当前快照完成后退出循环，已发布快照保留；忙碌关闭/退出请求会被记住。

测试是否保证所有环境可靠：测试只支持已验证的范围；跨机器、网络卷、超大容量、断电与长期运行仍需单独验证。
