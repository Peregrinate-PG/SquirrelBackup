# 松鼠备份0.2.0 使用说明

适用于macOS 13及以上的Apple Silicon电脑。先解压完整课程包，再打开03_可执行程序/SquirrelBackup.app。普通使用不需要安装Python或编译工具。第一次演示请使用附件工具生成的独立数据。

## 1 创建备份

进入“创建备份”，选择源目录，再为“备份文件”指定一个新的.sqbk文件名。备份位置应在源目录之外，不能覆盖已有备份。可勾选“压缩备份文件”；如勾选“密码加密”，输入至少8字节的密码并妥善保存。点击“开始备份”，等待日志与状态显示完成。

压缩没有收益时自动保存原始块。运行期间会显示阶段、路径和进度；点击“取消操作”请求清理未完成输出。取消需要等当前工作单元返回，已经成功发布的备份不会被删除。

## 2 验证、查看与恢复

进入“恢复与验证”，选择已有.sqbk文件；加密备份需要原密码。“验证完整性”检查文件格式与内容，“查看内容”显示条目清单。恢复时用“选择位置…”指定一个尚不存在的新文件夹名称，再点击“开始恢复”。程序不合并或覆盖已有目录。

密码错误或文件损坏时会显示原因，恢复不会发布结果。成功后应检查文件内容与目录结构；附件中的核对工具还可比较软硬链接、FIFO及声明范围内的元数据。忘记密码没有找回入口。

## 3 定时、变化检测与停止

进入“自动备份”，设置源目录、已有的存储目录、运行模式和保留份数。定时模式按正整数秒间隔生成完整快照；变化检测模式通过轮询等待目录变化稳定后备份。每次启动使用独立任务目录，只淘汰本次任务登记的旧快照。操作演示可设为3秒、保留2份。

点击“停止任务”后，已完成的快照保留，未完成的输出清理。关闭窗口或退出应用时，忙碌任务先请求取消并等待清理。自动任务只在应用运行期间有效；重新打开会恢复白名单表单参数，密码为空，任务不会自动续跑。

## 4 常见情况

| 提示或现象 | 处理方法 |
| --- | --- |
| 目标路径已经存在 | 换一个新的备份文件名或恢复目录名，保留原有内容 |
| 备份期间源目录发生变化 | 等源文件停止改动后重试；此功能不等同于文件系统原子快照 |
| 无法访问文件或保存位置 | 检查目录权限和可用空间；系统授权不足时按提示处理 |
| 停止后短时间仍显示工作中 | 等当前扫描、数据块或密码处理返回，再完成清理 |
| 自动任务没有立即生成新备份 | 检查模式与间隔；变化检测需观察到稳定变化，持续写入可能延迟 |

## 5 命令行与复建

CLI可独立运行：在03_可执行程序目录打开终端，执行./squirrel --help查看选项。创建备份、验证和恢复分别使用backup、verify、restore命令；路径含空格时加引号，恢复目标同样必须是新目录。

需要重建时，在04_项目源码目录执行make all；执行make test运行核心测试，make sanitize运行内存检查。重建需要macOS Command Line Tools；普通使用应用不需要这些工具。更完整的筛选和密码环境变量用法见源码README。

当前不提供网络备份、增量备份、系统后台常驻、ACL及文件flags恢复。具体支持范围、异常行为与测试边界以项目报告为准。
